Game Rules

1. Points System

Category Correct (Win) Wrong (Loss)
Cheese (Medium) +1 Point -1 Point
Meat (Hard) +2 Points -2 Points
Spinach (Extreme) Steal 2 Pts from ALL Punishment Card

🔥 Positive Combo (Winning Streak)

If you answer the SAME category correctly twice in a row, points are DOUBLED!

Example: Meat (+2) ➔ Next Meat (+4)

💀 Negative Combo (Losing Streak)

If you answer WRONG twice in a row, the penalty multiplies!

Example: Cheese (-1) ➔ Next Wrong (-2) ➔ Next Wrong (-3)...

3. Punishment Cards (7 Cards)

When you fail Spinach, pick a card:
⚫ Black: The Black Hole (-5 Pts)
🔴 Red: Divide Score / Give Points
🟣 Purple: Rival chooses for you
🟢 Green: Safe (-2 Pts only)
